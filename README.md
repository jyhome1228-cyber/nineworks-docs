# NINEWORKS DOCS

나인웍스 전용 문서 관리 웹앱의 1차 빌드입니다.

## 현재 구현
- 대시보드 / 거래처 관리 / 기본 공급자 정보
- 견적서 · 비교견적서 · 용역계약서 · 거래명세서 작성, 수정, 복제, 삭제
- 행 추가, 수량과 단가, 부가세 및 분할지급 자동 계산
- PDF 출력: 문서 미리보기에서 '인쇄 / PDF 저장' → 브라우저의 PDF 저장 사용
- 데이터 JSON 내보내기 및 가져오기
- 반응형 사이드바, 모바일 레이아웃

## 중요 제한사항
- **1차 화면 템플릿**입니다. 업로드한 HWP/XLSX/DOCX 원본을 픽셀 단위로 재현하거나 직접 해당 형식으로 내보내는 기능은 아직 없습니다.
- 브라우저 localStorage에만 데이터가 저장됩니다. 기기 간 동기화와 로그인은 아직 없습니다.
- 민감한 고객 정보는 공용 PC나 공유 브라우저에서 사용하지 마세요. 정기적으로 JSON을 백업하세요.
- GitHub 저장소가 public일 수 있으므로 실제 계약서 원본, 고객 사업자 정보, 직인, 서명 및 백업 JSON을 커밋하지 마세요.
- 비교견적서는 실제 제3자 견적 자료에 근거해야 합니다. 업체를 가장하거나 임의의 비교 금액을 만들어서는 안 됩니다.
- 법률 및 세무 적합성은 실제 사용 전 별도 검토가 필요합니다.

## 실행과 배포
별도 빌드 단계가 없는 정적 HTML/CSS/JS 앱입니다. GitHub Pages에서 main 브랜치 / (root) 배포를 켜면 실행할 수 있습니다.
이 저장소에는 별도의 서버 또는 Firebase 연결 설정을 넣지 않았습니다.
